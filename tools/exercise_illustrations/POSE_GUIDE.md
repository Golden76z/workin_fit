# Exercise illustration pose guide

You are drawing the tutorial illustration for bodyweight exercises of a fitness app.
Each illustration is generated by a small Python script using `figure.py` (same folder)
and rendered to a 1080x608 PNG on a near-black background.

## Style contract (non-negotiable)

- Gray silhouette figure(s), worked muscles highlighted in purple — visually consistent
  with the app's muscle-atlas diagram.
- **No text of any kind** inside the image (the app overlays localized text elsewhere).
- Dynamic exercise → **two poses**: start pose on the left, end/bottom/top pose on the
  right, purple `chevrons()` between them, white arrows showing the motion.
- Isometric hold (plank, wall sit, dead hang, L-sit…) → **one centered pose**
  (`scale≈1.2`), optionally small arrows hinting the effort direction.
- Exercise whose `muscleGroups` contains `cardio` → call `s.pulse_icon()` (top-left).
- Highlight levels: first non-cardio muscle group = `3`, all others = `2`.
  `cardio` itself is never a highlight (it has no body zone).
- Props are inferred from the movement, not just the `equipment` field:
  pull-up/chin-up/hang → `s.bar(...)` + `snap=False`; inverted/Australian row →
  low `s.bar(y≈380…420,…)`; wall exercises → `s.wall(x)`; step-up/box/dips/chair →
  `s.box(...)`; incline/decline push-up → `s.box(...)` under hands/feet.

## How to work (per exercise) — you MUST iterate visually

1. Read the exercise entry in `exercises_ref.json` (id, description, muscleGroups).
2. Pick the closest archetype below, copy it to `poses/<id>.py`, adapt the angles.
3. Run it: `cd tools/exercise_illustrations && python3 poses/<id>.py`
4. **Read (view) `out/<id>.png` with the Read tool.** Compare against the checklist.
5. Fix angles/positions and re-render. Repeat until the checklist passes.
   Never stop after the first render — at least one refinement look is mandatory.

### Checklist before calling an image done

- [ ] The movement is recognizable at a glance by someone who knows the exercise.
- [ ] Joints bend the right way (knees don't hyperextend backward, elbows bend one way).
- [ ] Contact points (feet/hands/forearms/back) rest on the ground or the prop —
      nothing floats, nothing sinks through the floor. `snap=True` grounds the
      figure automatically; verify the *right* body part is the lowest.
- [ ] Purple zones sit on the correct body parts (quads = front thigh, hamstrings =
      back thigh, calves = back of shin, glutes = top of the back of the pelvis,
      chest / abs = front torso, back / lowerBack = rear torso…). For lying poses
      set `front_hint` or zones will land on the wrong side!
- [ ] Arrows describe the motion and do not cross the figure's face/torso.
- [ ] Both figures fit the canvas with margins; nothing clipped at the edges.
- [ ] Two poses + chevrons for dynamic moves; one bigger centered pose for holds.

## Coordinate & angle system

- Canvas 1080x608, ground line at y=548. SVG y grows downward.
- Angles in degrees, **0 = pointing right, 90 = pointing UP**, 180 = left,
  -90 = straight down. Each angle is absolute (not relative to the parent joint).
- Segments: `torso` (pelvis→neck), `upper_arm` (shoulder→elbow), `forearm`
  (elbow→wrist, hand continues in the same direction), `thigh` (hip→knee),
  `shin` (knee→ankle), `foot` (ankle→toe), `head` (direction the head leans).
- `SideFigure` = profile view (default facing right). `FrontFigure` = facing viewer,
  `l_*` params = viewer-left limbs.
- `far_*` angles (SideFigure) draw the second (far-side) arm/leg in darker gray —
  use them whenever the two sides differ (lunges, climbers, single-leg moves).
  If omitted they mirror the near limb and stay hidden behind it.
- `snap=True` (default) translates the whole figure vertically so its lowest point
  touches the ground. Use `snap=False` for hanging/airborne poses and place
  `pelvis` manually. `clearance=N` keeps the figure N px above ground (jumps).
- `front_hint`: unit-ish vector pointing where the belly faces. Default is the
  facing direction — correct for standing/plank. **Set `(0, -1)` for supine
  (on the back) and `(0, 1)` for prone (face down)** so highlights land right.
- `highlights={"quads": 3, "glutes": 2}` — allowed keys: chest, shoulders, triceps,
  biceps, forearms, back, lowerBack, abs, obliques, quads, hamstrings, glutes, calves.

## Scene API

```python
s = Scene()                      # ground line included; Scene(ground=False) for none
s.add(SideFigure(...))           # or FrontFigure(...)
s.box(x, y, w, h)                # bench/step/chair, (x, y) = top-left corner
s.wall(x)                        # vertical wall line
s.bar(y, x0, x1)                 # pull-up bar with posts; posts=False for floating bar
s.line(a, b)                     # generic prop line (towel, door edge…)
s.arrow((x1,y1), (x2,y2), curve=0)   # white motion arrow; curve bows it sideways
s.chevrons(x, y)                 # purple '>>' transition marker between the 2 poses
s.pulse_icon()                   # small purple heartbeat, top-left (cardio moves)
s.save("<exercise_id>")          # writes out/<id>.svg + out/<id>.png
fig.j["knee"], fig.j["wrist"]…   # joint coords after snapping — use to anchor props
```

A figure standing at scale 1.0 is ~350 px tall. Two side-by-side poses: centers
around x≈300 and x≈770. Single hold pose: center x≈480–540, scale 1.2–1.3.

### Hanging from a bar (pull-ups, dead hang…)
```python
s = Scene()
s.bar(120, 340, 740)
f = SideFigure(pelvis=(540, 330), torso=88, upper_arm=155, forearm=95,
               thigh=-95, shin=-125, foot=-60, snap=False, scale=1.1,
               highlights={"back": 3, "biceps": 2})
s.add(f)   # tune pelvis so the hands wrap the bar; check f.j["hand"] ≈ bar y
```
After rendering, verify hands touch the bar; adjust `pelvis`/arm angles until they do.
You can also compute: print(f.j["hand"]) and shift pelvis by the y-difference.

## Tips that save iterations

- Legs in plank-family poses point back-DOWN: thigh/shin ≈ 195–210, foot ≈ -105.
- Kneeling: knee is a ground contact — thigh ≈ -115 (hip above-behind knee),
  shin ≈ 175 (pointing back along the floor), foot ≈ -140 (toes tucked) works.
- Sitting on the floor: pelvis is the lowest point; thigh ≈ 25…40, shin ≈ -35…-60.
- Arms "along the body" need a small forward offset to stay visible: -78/-74.
- When both figures are the same archetype (e.g. two plank variants), keep angle
  differences small and meaningful — the eye compares the two poses.
- Use `curve` on arrows to wrap around the figure instead of crossing it.
- Airborne (jump) pose: `snap=False` or `clearance=40…90`, and add small
  ground-shadow? No — just leave the gap; the arrows communicate the jump.
- To anchor a box under a foot/hand: render once, print `fig.j`, place the box
  so its top edge equals the joint y + half limb width (≈10–16 px).
